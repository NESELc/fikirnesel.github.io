# Platform logoları
Ana sayfadaki logolar Simple Icons 11.15.0 paketinden alınmıştır (CC0-1.0).
Kaynak: https://github.com/simple-icons/simple-icons/tree/11.15.0/icons
Lisans: https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md
Dosyalar: netflix.svg, youtube.svg, spotify.svg, openai.svg, primevideo.svg.
SVG geometrileri korunmuş; yalnızca marka rengi (OpenAI için koyu nötr) eklenmiştir.
Markaların adları ve logoları ilgili sahiplerine aittir; Simple Icons resmî marka dağıtıcısı değildir.
Logolar yalnızca karşılaştırılan hizmetleri tanımlamak amacıyla kullanılır.
Araç görseli mevcut /inc/peugeot-e2008.jpg dosyasından kullanılır; fiyat sıralaması iddiası taşımaz.
